            03 — Guide

            Installer et vérifier

            Vérifier l'empreinte SHA-256 d'un fichier

            Chaque fichier est affiché avec son empreinte. Compare-la à celle de ton téléchargement : si elles diffèrent, ne lance pas le fichier.

            Get-FileHash .\installer.exe -Algorithm SHA256

            À lancer dans PowerShell, dans le dossier où se trouve le fichier.

            Windows SmartScreen affiche un avertissement

            Mes exécutables ne sont pas toujours signés numériquement (les notes de J.A.R.V.I.S le précisent). Windows peut alors afficher « Windows a protégé votre ordinateur ». Après avoir vérifié l'empreinte, clique sur Informations complémentaires puis Exécuter quand même.

            J.A.R.V.I.S : première installation
            1. Télécharge l'installateur et lance-le : aucun droit administrateur n'est nécessaire. Installer par-dessus une ancienne version conserve tes réglages, tes clés et la mémoire.
            2. L'installateur met en place Python 3.12 si besoin, puis les dépendances (quelques minutes, connexion internet requise).
            3. Lance J.A.R.V.I.S depuis le menu Démarrer ou le raccourci du bureau.
            4. Au premier lancement, l'assistant te demande ton nom et une clé d'IA (Gemini en propose une gratuite), teste ton micro et peut enregistrer ton empreinte vocale.
            RL Session Stats : installateur ou portable ?

            L'installateur (_x64-setup.exe) installe l'application et ses raccourcis. La version portable est un seul fichier à lancer, sans installation.

            L'overlay utilise uniquement l'API de statistiques locale et officielle de Rocket League (aucune injection, aucune lecture mémoire), donc il reste compatible avec Easy Anti-Cheat. Le jeu doit être en mode Fenêtré sans bordure pour que l'overlay s'affiche par-dessus.

            ModShift : installation avec npm

            ModShift demande Node.js 20.17+ ou 22.13+.

            npm install --global modshift

            Une fois installé : modshift ui ouvre une petite interface web locale, modshift interactive te guide mod par mod.

            D'où viennent les fichiers ?

            Les liens pointent directement vers les releases officielles de mes dépôts GitHub : aucun intermédiaire, aucun hébergement tiers. Les nombres de téléchargements et les empreintes sont ceux que GitHub indique.
