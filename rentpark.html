RentPark

Une plateforme de location de voitures réalisée en équipe : site web, API, administration Blazor et application Android.

01 — Principe

Ce qu'est RentPark

RentPark est un projet d'équipe de deuxième année de BUT Informatique (SAE). Il couvre tout le cycle : analyse, conception, base de données, puis trois applications qui partagent la même API.

Une première conception suivait les consignes du cours de PHP ; la seconde respecte au maximum les principes SOLID grâce aux services web.

02 — Fonctionnalités

Ce qu'il propose

Site de réservation

Catalogue de véhicules, réservation en ligne et devis imprimable (HT, TVA 20 %, TTC).

API commune

Une seule API web pour le site, l'administration et l'application mobile.

Administration Blazor

Tableau de bord, utilisateurs, clients, flotte, réservations et planning.

Application Android

Application en Kotlin (Retrofit) qui utilise la même API.

Rôles

Comptes client, employé et administrateur, chacun avec ses propres droits.

Alertes par e-mail

Notifications envoyées par SMTP.

03 — Technique

Sous le capot

Site
PHP 8, avec des tests PHPUnit.
Administration
Blazor sur .NET 9.
Mobile
Kotlin et Retrofit.
Données
MySQL, avec MCD, MLD et rapport de base de données.
Lancement
Une seule commande (start.ps1, start.sh ou docker compose) démarre la base, l'API, le site et Blazor.
Conception
Deux versions documentées : celle demandée en cours, puis une version revue selon SOLID.

04 — Démarrage

Lancer le projet

  1. Avec Docker seul, sans rien installer d'autre

    git clone https://github.com/NeyorDEV/RentPark.git
cd RentPark
docker compose up --build

  2. Le site s'ouvre sur localhost:9990, l'administration Blazor sur localhost:5019 et l'API sur localhost:8880.
